Ready to annotate a video?

Annotate the end of each peristaltic step by marking Cycle End frames. Annotations will be saved to a CSV file that you can download or upload directly to me.

How it works

  • Use the play/pause button (Spacebar), the frame slider, or the arrow keys (← or →) to move frame-by-frame.
  • Press the C or M key (or click the Cycle End button) to label the end of a step.
    Try to be as precise as possible, but don't worry too much - this is why multiple people are helping out! No need to go back and forth to optimize things unless you are certain you've made a mistake.
  • If you need to, press Backspace to clear the label for the current frame (or use the 'Clear Selected' button).
  • Slow down the video to make it easier to see the steps if you'd like. Use the dropdown menu below the video slider to change the playback speed.
  • When you're done, click "Download CSV" to save your labels, or "Upload Annotation Labels" to upload them directly to me.

Tip: Make sure the frame number shown in the UI matches what you expect—this ensures your annotations align exactly with the video frames used in offline analysis. If the frame number doesn't match what you see in the video, pause the video, manually scroll back a few frames and restart the video. That should bring them back into sync.
