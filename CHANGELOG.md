# Changelog

All notable changes to the Video Annotator project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Comprehensive documentation (user guide, developer guide, API reference)
- Performance profiling tool for identifying bottlenecks
- Visualization tool for annotation statistics
- Export tool for exporting annotations to different formats
- Configuration editor for customizing the application
- Modular architecture with clear separation of concerns
- Unit tests and integration tests
- CI/CD pipeline for automated testing
- Conda environment for dependency management

### Changed
- Reorganized repository structure for better maintainability
- Removed global variables and implemented proper object-oriented design
- Improved error handling and logging
- Enhanced user interface with better organization and more options
- Updated dependencies to latest compatible versions

### Fixed
- Fixed memory leaks in video playback
- Fixed issues with annotation loading and saving
- Fixed UI responsiveness issues
- Fixed compatibility issues with different video formats

## [0.1.0] - 2023-01-01

### Added
- Initial release of the Video Annotator
- Basic video playback functionality
- Basic annotation functionality
- Basic visualization functionality
