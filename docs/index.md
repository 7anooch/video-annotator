# Video Annotator Documentation

Welcome to the Video Annotator documentation. This documentation provides comprehensive information about using and developing the Video Annotator application.

## Overview

Video Annotator is a tool for annotating video frames with behavioral labels, primarily designed for neuroscience research. It allows researchers to:

- Navigate through videos frame by frame
- Annotate frames with customizable labels
- Visualize annotations as ethograms
- Generate ground truth from multiple annotations
- Analyze and compare annotations
- Export annotations to different formats
