## Overview

Video Annotator is a tool for annotating video frames with behavioral labels. It is primarily designed for neuroscience research, but can be used for any application that requires frame-by-frame video annotation.

The application provides a user-friendly interface for navigating through videos, annotating frames, and visualizing the annotations. It also includes tools for analyzing annotations, comparing annotations from multiple annotators, and exporting annotations to different formats.

## Key Features

- **Frame-by-frame Navigation**: Navigate through videos frame by frame using keyboard shortcuts or buttons.
- **Customizable Labels**: Define your own labels and keyboard shortcuts for quick annotation.
- **Annotation Visualization**: Visualize annotations as ethograms, label distributions, and more.
- **Ground Truth Generation**: Generate ground truth from multiple annotations.
- **Analysis Tools**: Analyze and compare annotations from different annotators.
- **Export Options**: Export annotations to different formats (CSV, JSON, MATLAB, etc.).
- **Video Processing**: Extract frames, trim videos, and process video files.
- **Configuration Options**: Customize the application to suit your needs.
- **Configuration Profiles**: Create and switch between different configuration profiles for different use cases.

## Workflow

A typical workflow for using the Video Annotator application:

1. **Install** the application and its dependencies.
2. **Configure** the application with your preferred labels and settings.
3. **Load** a video file for annotation.
4. **Navigate** through the video frame by frame.
5. **Annotate** frames with your defined labels.
6. **Visualize** the annotations to identify patterns.
7. **Analyze** the annotations to extract insights.
8. **Export** the annotations for use in other applications.
